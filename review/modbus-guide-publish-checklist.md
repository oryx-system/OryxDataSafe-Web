# Modbus Check 설명·배포 문서 게시 전 확인

사용자가 Modbus Check의 공개 배포와 홈페이지 소개·다운로드 연결을 지시했습니다. 홈페이지 상세 설명과 `release/modbus-check/README.md`, `USER_GUIDE.ko.md`는 게시할 로컬 산출물입니다. `release/`는 홈페이지의 `public/` 디렉터리가 아니며 이 문서를 추가하는 것만으로 설치 파일이나 가이드가 운영 사이트에 배포되지는 않습니다.

사용자가 승인한 **Modbus Check 0.2.0-rc.7 사전 공개(prerelease)**가 2026-10-20 23:37:10 UTC에 게시됐습니다. 공식 릴리스 JSON의 `draft:false`, `prerelease:true`, 공개 시각과 설치 자산의 URL·SHA256을 대조했습니다. 이 홈페이지 클라우드 환경에서 비로그인 실제 다운로드의 바이트·해시 대조도 완료했습니다. 홈페이지 운영 반영은 아직 완료로 보고하지 않습니다.

포함된 Node.js는 **24.22.0**이며 예고된 HIGH 보안 업데이트의 수정은 포함하지 않습니다. 앱 영향이 없다고 보장하지 않습니다. 이 한계를 고지한 사전 공개 승인과 보안 수정 완료를 구분합니다. EXE는 코드 서명되지 않았습니다.

## 반영 근거와 버전 구분

- 기존 홈페이지의 프로그램 소개·문체·3개 언어 구조.
- 부모가 인계한 기존 rc.6 기능 명세와 rc.7 공식 공개 정보를 반영했습니다. Windows x64·Chrome/Edge, TCP·RTU·ASCII, 주소 입력·표시, 자료형·구성 주소, Binary, 기록·파일·Excel, 트렌드·점 크기, 검색·쓰기의 지원 범위를 유지합니다.
- rc.7의 단위 시험 **241개**와 설치 관련 확인 **11개**, 격리된 환경의 설치·업데이트·제거·재설치 및 **rc.6→rc.7 업데이트** 통과 결과를 인계받았습니다. 배포와 동일한 EXE를 사용한 설정·기록 보존, 실행 경로별 콘솔 flash·네이티브 창 아이콘·앱 식별자 검사 범위와 실제 현장 장비 호환 검증을 구분합니다.
- 편집용 XLSM 완료. 주표의 `Bit 0:`~`Bit 15:` 비트명·설명 직접 입력, 32·64비트 및 ASCII 구성 행의 잠금·해제, 묶음 축소 시 이전 설명 복원과 수식처럼 보이는 이름의 TEXT 보존을 반영했습니다. 이번 인계의 완료 상태를 최신 기준으로 적용합니다.
- 실제 Excel 시험에는 표준 양식·현재 데이터·주소 끝 경계와 일반 ‘다른 이름으로 저장’ XLSX가 포함됐습니다. 시험 자료의 매크로 제거 전후 인쇄 이미지 차이는 **0**이었습니다. 이 결과를 모든 문서의 동일성이나 XLSM 전용 편집·잠금 동작의 매크로 제거 후 유지로 확대하지 않습니다.
- **rc.6 표준 양식의 실제 주소 목록은 PDU 0~500의 고유 주소 501개이며 누락·중복이 없음을 확인했습니다.** 화면의 읽기 범위를 143개 또는 4개 주소로 설정해도 표준 양식 목록은 같습니다. `No`는 순번이고 PDU 주소가 아니며 비트 보조 행·서식용 빈 행은 주소 개수에서 제외합니다. 이 결과는 표준 양식의 주소 목록에 한정하며 현재 데이터 내보내기·로그·전체 PDU 0~65535·모든 메타데이터·Float64 문제 해결의 검증으로 확대하지 않습니다.
- rc.7 공식 릴리스에서도 표준 양식의 첫·마지막 PDU 0/500과 고유 주소 501개, 누락·중복 없음의 확인 결과를 인계받았습니다. 이전 rc.6 검증 이력과 실제로 확인한 범위를 유지합니다.
- 이 홈페이지 클라우드에서 자격증명·쿠키 없이 설치 EXE를 독립 다운로드했습니다. HTTP200, 리다이렉트1회, **35,030,462바이트**와 SHA256이 공식 자산 값과 일치했습니다. SHA256SUMS.txt도 HTTP200으로 받아 공식 자산 해시 및 설치 EXE의 기재 해시와 대조했습니다. 이 확인에서 EXE를 실행하지는 않았습니다.
- Float64를 선택한 뒤 Excel 전체가 멈춘다는 제보는 여전히 재현하지 못했고 해결 여부도 확인되지 않았습니다. rc.7 시험 통과를 완전 해결 근거로 사용하지 않습니다.
- 작업 표시줄의 실제 화면 캡처 검증은 검수 환경의 화면 핸들 오류로 완료하지 못했습니다. 네이티브 창 아이콘·앱 식별자 검사 통과를 모든 시각 검증 완료로 표현하지 않습니다.
- 승인된 개인·회사 업무용 무료 사용, 소스 비공개, 설치 파일 재배포 또는 프로그램 수정·재판매·OEM 별도 허가, 타사 라이선스 권리 예외 조건.

기존 로컬 준비 커밋을 보존하며 최신 main과 배포 경로를 확인했습니다. 실제 공개 URL·해시 인계와 독립 다운로드 대조는 완료됐으며 부모의 진행 순서에 따라 홈페이지 최종 검증·푸시·운영 반영·운영 링크 확인을 이어갑니다. 정확한 지원 Windows 최소 버전·관리자 권한 요구·설치 위치·제거 후 파일 정책은 임의로 만들지 않았습니다. 앱 개발 소스 저장소는 비공개로 유지합니다.

이 문서는 내부 게시 검토용입니다. 비공개 개발 소스의 코드·저장소 링크·고객 주소맵·현장 정보·설치 검수용 식별정보를 공개 문서에 옮기지 않습니다.

## 게시 직전 검증

1. 최종 설치본과 기능별 설명을 대조하고 위 미확인 항목을 해소하거나 해당 주장을 제외합니다.
2. 홈페이지 한국어·영어·러시아어 문구가 같은 지원 범위와 사용 조건을 설명하는지 확인합니다.
3. 320~1440px와 큰 글자 설정에서 긴 설명·표·버튼이 넘치지 않는지 확인합니다.
4. 실제 제품 화면이 필요하면 승인된 검수용 데이터로 촬영합니다. 이미지가 없으면 가짜 화면을 만들지 않습니다.
5. 표준 양식의 고유 PDU 0~500 주소 501개 확인 결과와 집계 방법을 문서에 유지합니다. 이 결과를 현재 데이터 내보내기·로그·전체 PDU 범위의 검증으로 확대하지 않습니다. 후속 버전에서 목록 동작이 바뀌면 해당 버전의 결과를 다시 대조합니다.
6. 확정된 0.2.0-rc.7 사전 공개와 실제 빌드의 Node 24.22.0·HIGH 보안 수정 미포함, EXE 미서명·검증 범위·알려진 한계·파일명·버전·SHA256·타사 고지를 문서와 일치시킵니다. 보안 수정 완료나 Float64 완전 해결을 주장하지 않습니다.
7. 실제 GitHub 릴리스 자산 URL과 비로그인 공개 다운로드를 확인하고 다운로드한 파일의 SHA256을 인계받은 원본과 대조합니다. 예시 링크나 확인되지 않은 파일을 등록하지 않습니다.
8. 확인된 배포 지시에 따라 확정된 릴리스 정보와 공개 상태를 홈페이지 3개 언어·README·가이드에 일치시킵니다. 0.2.0-rc.7을 사전 공개 시험판으로 표시하고, 검수 범위·알려진 한계와 부모의 독립 다운로드 대조 결과를 확인한 뒤 홈페이지 다운로드를 연결합니다.
9. 기존 홈페이지 최신 main·사용자 변경을 다시 확인하고 시험을 마친 뒤 허용된 시점에 게시합니다. 운영 목록·상세 링크와 다운로드 파일 해시를 다시 대조합니다. 비공개 소스 저장소의 가시성은 변경하지 않습니다.
